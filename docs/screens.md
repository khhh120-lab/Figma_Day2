# screens.md — 화면 설계서

## 요금제 목록

### 목적
이용 가능한 요금제를 안내한다.

### 라우트
/plans

### 구성 요소
- Header: 화면 제목
- Logo: U+ 로고
- FilterChip: 요금제 필터
- Card/Plan: 요금제 목록
- Tag: 추천 표시
- Chip: 할인 프로모션 표시
- Button: 자세히

### 상태
- 기본: 요금제 필터와 요금제 목록을 표시한다.
- 로딩: 첨부 자료에 정의되지 않음.
- 빈: 첨부 자료에 정의되지 않음.
- 에러: 첨부 자료에 정의되지 않음.

### 이동
- 들어오는 곳: 흐름의 진입 지점, 요금제 상세에서 뒤로 이동
- 나가는 곳: 요금제 상세 (/plans/[id])

## 요금제 상세

### 목적
선택한 요금제의 요금과 제공 혜택을 안내한다.

### 라우트
/plans/[id]

### 구성 요소
- Header: 화면 제목
- icon/arrowLeft: 뒤로 이동
- Tag: 추천 표시
- Card/Price: 월 요금
- List/Row: 기본 제공 항목
- OptionItem: 포함 혜택
- BottomCTA: 월 납부 금액과 신청 영역
- Button: 구독 신청하기

### 상태
- 기본: 선택한 요금제의 요금, 기본 제공 항목, 포함 혜택을 표시한다.
- 로딩: 첨부 자료에 정의되지 않음.
- 빈: 첨부 자료에 정의되지 않음.
- 에러: 첨부 자료에 정의되지 않음.

### 이동
- 들어오는 곳: 요금제 목록 (/plans), 구독 신청에서 취소
- 나가는 곳: 구독 신청 (/apply), 뒤로 이동 시 요금제 목록 (/plans)

## 구독 신청

### 목적
선택한 요금제의 구독 신청에 필요한 입력 정보를 안내한다.

### 라우트
/apply

### 구성 요소
- Header: 화면 제목
- icon/arrowLeft: 이전 화면 이동
- List/Row: 선택한 요금제와 월 요금
- Input: 이름, 휴대폰 번호
- Checkbox: 개인정보 수집·이용 동의
- BottomCTA: 신청 영역
- Button: 신청하기

### 상태
- 기본: 선택한 요금제와 월 요금, 신청 정보 입력란, 동의 항목을 표시한다.
- 로딩: 첨부 자료에 정의되지 않음.
- 빈: 첨부 자료에 정의되지 않음.
- 에러: 첨부 자료에 정의되지 않음.

### 이동
- 들어오는 곳: 요금제 상세 (/plans/[id])
- 나가는 곳: 신청 완료 (/complete), 취소 시 요금제 상세 (/plans/[id])

## 신청 완료

### 목적
구독 신청 완료 여부와 신청 내역을 안내한다.

### 라우트
/complete

### 구성 요소
- Header: 화면 제목
- icon/arrowLeft: 이전 화면 이동 표시
- icon/doneMark: 신청 완료 표시
- List/Row: 신청 번호, 요금제, 월 요금, 신청 일시, 신청자
- BottomCTA: 하단 버튼 영역
- Button: 요금제 더 보기

### 상태
- 기본: 구독 신청 완료 안내와 신청 내역을 표시한다.
- 로딩: 첨부 자료에 정의되지 않음.
- 빈: 첨부 자료에 정의되지 않음.
- 에러: 첨부 자료에 정의되지 않음.

### 이동
- 들어오는 곳: 구독 신청 (/apply)에서 신청 완료
- 나가는 곳: 흐름의 종료 지점. 화면에 표시된 뒤로 이동 및 ‘요금제 더 보기’의 목적지는 flow.png에 정의되지 않음.
